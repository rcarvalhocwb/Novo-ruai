# Relatório de problemas

Caminhos relativos à raiz do `iluminadarua2025` (commit `66d7ba2`). As políticas RLS foram lidas das migrations. **Confirme no banco em produção** com:

```sql
select tablename, policyname, roles, cmd, qual, with_check
from pg_policies where schemaname = 'public' order by tablename;
```

Severidade: **CRÍTICO** (perda ou fraude de dinheiro ou dados, explorável agora) · **ALTO** (gera divergência ou impede conciliação) · **MÉDIO** · **BAIXO**.
